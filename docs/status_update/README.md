# Status update, 13 October 2026

Figures for the team channel, generated by `python3 sim2/make_status_update.py` from the result files in `figures/` (every number below is read from those files).

## Post

When clinicians act on a hospital AI alert, the model's measured accuracy changes even though nothing is broken, and we show that standard monitoring blames the wrong cause, while our method gets it right by holding the alert back for a random group of patients.

All the simulation experiments are done; the one missing piece is MIMIC-IV, real hospital records that someone with approved PhysioNet access needs to run through `sim2/run_e6.sh all <username>` on their own computer (about 3 GB to download, 20 to 40 minutes to run, and only summary numbers are saved).

## Captions

`01_workflow.png`

All the simulation work is done; the one missing piece (red) is the MIMIC-IV run, which needs someone with approved access to the data to run our script on their own computer.

`02_attribution.png`

In a simulated hospital where the only change is clinicians acting on the alert, standard monitoring blames a change in patients' risk, while our method correctly blames the alert.

`03_more_data.png`

When the patients the alert flags were never treated before it existed, the usual correction gets the alert's effect backwards (−0.009 instead of +0.027), and more data only makes it more confident.

`04_retraining.png`

Retraining on recent data teaches the model that treated patients are low risk, so the alert keeps switching off and on, and the accuracy score looks best exactly when the alert helps no one.

`05_refit_rules.png`

Deciding when to retrain with our method never cost extra bad outcomes in our tests, while the same rule using standard monitoring cost up to 11.5 extra per 100 patients.

`06_auroc_vs_benefit.png`

The more often clinicians act on alerts, the more bad outcomes are prevented and the lower the model's measured accuracy, so falling accuracy after launch can mean the alert is working.

`07_prevalence.png`

When the bad outcome is uncommon (7 to 14% of patients, as on real wards), a working alert lowers prediction error, which standard monitoring reads as patients' risk going down.

`08_real_covariates.png`

On real ICU patients from two hospitals (a public stand-in until the MIMIC-IV run), standard monitoring again mistakes the alert's effect for a change in risk, while our method gets it right.
